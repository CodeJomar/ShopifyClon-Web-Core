## Decisiones tomadas
1. **Correo de contacto obligatorio**: el contrato lo marca opcional, pero la API responde `VAL-001` cuando falta. Se pide siempre y se prellena con el correo del perfil. TODO(Q-W-006).
2. **Campo de subdominio**: la validación de formato y de reservados se hace en la web antes de enviar; la unicidad la decide la API (`TIE-001` en el campo).
3. **Tarjeta de plan**: componente propio del módulo (`modules/tienda/components/tarjeta-plan.tsx`), con `role="radio"`, `aria-checked` y flechas. Borde de 1.8 px fijo; anillo de 3.5 px al seleccionar; sin tocar `shared/components`.
4. **Formato de precios**: `formatearDinero(precio, moneda)` con la moneda del plan (los planes vienen en USD).
5. **Límites nulos**: `null` o ausente se muestra como ilimitado.
6. **Destino tras el login** (sin `siguiente`): 0 tiendas → `/cuenta/tiendas/nueva`; 1 → `/panel` (el proxy ya fija la tienda); varias → `/cuenta/tiendas`. Con `siguiente`, se usa `destinoSeguro`.
7. **`/panel`** es un marcador (W-007 lo reemplaza). Sin tienda activa (404 / `SEG-001`) redirige a `/cuenta/tiendas`.
8. **`/cuenta`** no tiene enlace nuevo: el botón "Mis tiendas" se añadió en la misma tarjeta del marcador de cuenta.
9. **Campos de `GET /panel/tienda`**: `TiendaActivaDto` lo tipa solo con `nombre`, `subdominio` y `moneda` opcional. TODO(Q-W-006): confirmar la forma completa de la respuesta.
