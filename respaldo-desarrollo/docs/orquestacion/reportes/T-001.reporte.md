## Decisiones tomadas (no estaban en la tarea)
- **Surefire `api.version=1.44`** (en `pom.xml`): el Docker local (Docker Desktop, motor 29.7.2) rechaza la API 1.32 que usa por defecto el docker-java de Testcontainers 1.19.8 (Boot 3.3.4) y devolvía `Could not find a valid Docker environment`. Se resolvió con una propiedad de sistema de las pruebas, sin cambiar versiones de dependencias. Si en otro equipo molestara, puede quitarse.
- **`jwt.secreto` de pruebas en Base64**: `JwtProveedor` decodifica el secreto como Base64 (falló con "Illegal base64 character"), así que el valor ficticio es Base64 (80 caracteres).
- **`spring.jpa.show-sql=false` y `leak-detection-threshold=0`** en el perfil `test` para reducir ruido del log.
- **`DotenvInitializer` no se modificó**: solo está registrado en `ShopifyApplication.main(...)`, por lo que los tests (`@SpringBootTest`) nunca lo ejecutan; no hay carga de `.env` en pruebas. Verificado renombrando `.env`.
- `MigracionesTest.existenLosRolesDeTienda` usa `contains` (no igualdad exacta) porque `Roles` puede traer otros roles de V1.
- `flyway_schema_history` se consulta filtrando `version IS NOT NULL`.
